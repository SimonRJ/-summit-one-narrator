Use answer information, then check independently

Use multiple-choice options sensibly, and always answer the question that was asked.

In a multiple-choice question, the options are information. You can test them, or rule some out, without solving the whole problem. But an option that merely looks familiar is not evidence. Every choice still has to be checked against the question.

Question setters include options that match common mistakes, and options that match a step along the way. Using the options well, and rereading what was asked, protects you from both.

Which of these numbers is a multiple of both four and nine: fifty-four, sixty-four, seventy-two, eighty-one or ninety? Pause and think about the quickest way to rule options out.

A multiple of four is even, so eighty-one goes. Half of fifty-four is twenty-seven, which is odd, so fifty-four is not a multiple of four. The same happens with ninety. That leaves sixty-four and seventy-two.

For nine, add the digits. Sixty-four gives ten, so it is not a multiple of nine. Seventy-two gives nine, so it is. The answer is seventy-two, option C. Two quick tests replaced any long division.

Now the other trap. A book costs twelve dollars and a pen costs three dollars less. What do two pens cost? One pen costs nine dollars, and nine is among the options. But the question asks for two pens: eighteen. Always reread the request before choosing.

When an equation is hard to solve directly, try the options in it. Suppose two times x plus five must be nineteen. Try six: the result is seventeen. Here bigger choices give bigger results, so try seven. That gives nineteen. Check how the expression changes before using a trial to choose a direction.

Rule options out with quick tests. Do not choose a number just because it appeared in your working. Reread what was asked before you answer. Notebook challenge: which of forty-five, sixty, seventy-five and ninety is a multiple of both four and five?
