T10.2

Remember enough information, but no more

Decide what a repeating process must remember: its state.

1:55 · Full HD

Try it in your notebook

The first number is 7. Triple each number and keep only its last digit to get the next. What is the 30th number?

Check your reasoning

7, 1, 3, 9 repeats; 30 = 4 x 7 + 2, so the 30th is 1.

Try a variation

Start with the digit 3. At each step double the current digit and keep only the last digit. What is the digit after 10 steps?

See the worked answer

After one step the digit is 6. The next digits are 2, 4, 8 and then 6 again. Steps 1, 5 and 9 all give 6, so step 10 gives 2.

Read the transcript

0:00 Decide what a state must remember

In a process with a fixed rule, the state is everything you need to work out the next step. The same state must lead to the same next state. So once a state repeats, the whole path repeats from there. Finding the state is the key to long-run questions.

0:16 Use a cycle to reach a distant term

Questions about the hundredth or thousandth step look impossible. But if the states repeat in a short cycle, you only need the position inside the cycle.

0:26 Double 3 and track the last digit

Start with three. Each time, double the number and keep only its last digit. The list begins three, six, two, four, eight, six. What is the fiftieth number? Pause and look for a repeat.

0:42 Find where the cycle begins

After the first number, the list repeats six, two, four, eight. Notice that three itself never comes back. The cycle starts at the second number, not the first.

0:53 Locate the 50th term after the initial 3

From the second number to the fiftieth there are forty-nine numbers. Forty-nine is twelve complete cycles and one more. So the fiftieth number is the first in the cycle: six.

1:05 Remember two digits for a sum recurrence

Sometimes one number is not enough to be the state. If each number is the last digit of the sum of the previous two, then seeing a one does not tell you what comes next. You need the last two numbers. The state is a pair.

1:19 Track a robot’s previous direction

In the same way, if a robot may not reverse its last move, its position alone is not the state. You must also remember which way it just moved. Remember enough to know what can happen next, and no more.

1:33 Triple 7 and find the 30th last digit

Decide what the state is. Find where a state first repeats. Then use a remainder to locate the position in the cycle. Notebook challenge: start with seven as the first number. To get each next number, triple the current one and keep only the last digit. What is the thirtieth number?
