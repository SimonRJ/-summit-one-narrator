Split by the restriction that changes the choices

Split a count into cases using the restriction that changes the number of choices.

Read the transcript

Some counting problems are too awkward to do in one go. The trick is to split them into cases. Good cases have two properties: no outcome belongs to two cases, and every outcome belongs to one.

Multiplying choices only works when the number of choices does not depend on what you chose earlier. When a restriction changes the choices, a single multiplication breaks. Splitting at the restriction repairs it.

Using the digits zero, one, two, three and four, with no digit repeated, how many even three-digit numbers can be made? Pause and think about which place causes the trouble.

The number must be even, so the last digit is zero, two or four. But zero is special, because a number cannot start with zero. So split by the last digit: either it is zero, or it is two or four.

If the last digit is zero, the first digit has four choices and the middle has three: twelve numbers. If the last digit is two or four, the first digit cannot be zero or the last digit, leaving three choices, and the middle has three. That is two times three times three: eighteen numbers.

The cases cannot overlap, because a number has only one last digit. Add them: twelve plus eighteen is thirty.

Sometimes it is quicker to count what is forbidden. Two switches have four settings altogether. If "both on" is not allowed, subtract that one, leaving three. Counting everything and subtracting the unwanted part is called using the complement.
