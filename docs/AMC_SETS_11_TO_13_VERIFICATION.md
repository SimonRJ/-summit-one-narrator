# AMC original practice Sets 11–13

Each set contains a 20-minute Part A worth 70 marks and a 40-minute Part B worth 65 marks. All six papers are active in the AMC exam centre as single-attempt practice.

An independent calculation checked each of the 90 answers. Depending on the question, methods included exact fractions, separate coordinate models, enumeration of possible assignments and an exhaustive search of legal moves. Every question has a worked solution and an assigned learning skill. The originality review inspected close mathematical and wording matches, revised overlapping tasks and found zero exact stem matches in the final editions.

For each paper, two temporary test sittings ran through the authenticated simulator. A completed paper received full marks. Leaving the last response blank reduced the score by the value of that question. Each test verified the timer, sealed report, solution and skill feedback, rejected late changes and a second sitting, then rolled back the temporary records.

All published question fields matched the reviewed private editions. The reference fingerprints for the 19 authentic papers, their 570 questions and 152 linked problems matched before and after each publication.
