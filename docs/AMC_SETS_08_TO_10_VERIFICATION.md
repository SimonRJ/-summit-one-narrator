## Content checks

Independent calculations checked every answer across the 90 questions. The checks included exhaustive searches of permitted arrangements and moves, exact probability calculations, coordinate geometry, and cell-by-cell checks of diagrams. All ten figures rendered successfully and have text descriptions. Every question has a worked solution and a learning skill for feedback after submission.

The originality review compared each set with the existing exams and learning problems, including authentic source text and solutions. Close wording and mathematical matches prompted revisions. The final editions returned zero exact stem matches.

All twelve sittings verified the assigned deadline, question count, scoring, feedback and stable sealed report. The simulator rejected a further response after submission and a second sitting on the same paper. The temporary records rolled back.
