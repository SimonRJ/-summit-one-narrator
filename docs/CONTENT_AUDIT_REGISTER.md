# Content audit register

The per-problem register for the 566 standard lesson problems is [content-audit-register.csv](content-audit-register.csv). It is generated by `python tools/content/build_audit_register.py` and contains no prompts, answers or solutions.

## Columns

| Column | Meaning |
|---|---|
| `id`, `session`, `technique`, `role`, `visit`, `difficulty` | Identity. `role` is `try` (guided) or `transfer`. |
| `content_fingerprint` | First 10 characters of the MD5 of the current statement: the content version. |
| `assurance_level` | `independent` = this exact problem is recomputed by its own check. `family_check` = only its generator family is recomputed. |
| `verification_method` | The script that provides that assurance. |
| `same_structure_elsewhere` | How many other lesson problems have the same statement once numbers are removed. |
| `individually_reviewed` | Whether a reviewer wrote or read this statement and solution one by one. |
| `has_recorded_attempts` | `yes - frozen` means a learner has answered it and it must not be changed. |
| `diagram` | Diagram review status for the original lesson prompt. |
| `status` | One of: Verified and suitable; Correct by family check, awaiting individual review; Repetitive and requires redesign. |
