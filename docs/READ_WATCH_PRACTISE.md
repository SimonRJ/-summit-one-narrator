# Lesson text and practice through S068

**19 November 2026 — parent and maintainer guide.** The cutoff is the film labelled **S068**, in course order. There are 55 teaching films in the first 68 slots; nine MAWA investigations and four workshops occupy the other 13 slots. The [continuation through the end of the course](LATER_LESSONS.md) covers the remaining 228 teaching sessions.

Each of these 55 teaching lessons has a short introduction, one worked example, a specific thing to look for in the existing film, and a practice sequence. There are four newly written problems per lesson with hints and solutions. The first asks the learner to apply the idea; later questions change the conditions or combine steps, and the last uses a less familiar setting. Selected challenges from the earlier bank sit between the new questions. The recap gives a test or question the learner can carry into the next problem. Twelve opening examples also have labelled diagrams.

**Worked examples across the course.** Read the problem and try a first move on paper. Choose **Show the first step** for a hint or **Show all steps** for the complete example. If a practice answer is incorrect, **Try a next step on paper** opens a question-specific hint, or the lesson reminder if the hint was already opened. The student can also go directly to the worked solution. The recap identifies correct answers that used support.

Seventeen lessons include optional diagrams that let the student change a quantity and inspect the result. Examples are available on the public film pages for [cube layers and silhouettes](https://simonrj.github.io/-summit-one-narrator/watch-intro-s006.html), [rectangles containing a cell](https://simonrj.github.io/-summit-one-narrator/watch-lesson-intro.html?slot=82) and [area with fixed fencing](https://simonrj.github.io/-summit-one-narrator/watch-lesson-intro.html?slot=85).

In any of those diagrams, open **Always, sometimes or never?** to investigate three claims. Move a control and choose **Use this example** to record what the diagram shows. For a claim that is sometimes true, find one example that supports it and one that disproves it. The nine original claims adapt the reasoning routine described by [NRICH](https://nrich.maths.org/problems/always-sometimes-or-never-shape) and [Fawn Nguyen](https://fawnnguyen.substack.com/p/always-sometimes-never).

Ten domino lessons also have a board you can tile by choosing two squares that share an edge. Use **Show checkerboard colours** to see what each domino covers. Try the six-square mat, then investigate whether having the same number of dark and light squares guarantees a tiling. The boards and proofs were written for Summit One, inspired by [Michael LoMuscio’s interactive tiling puzzles](https://github.com/michaellomuscio/L-Tromino-Tiling-Puzzle). [Try the S036 board](https://simonrj.github.io/-summit-one-narrator/watch-lesson-intro.html?slot=36#lessonModel).

Six lessons include a route-counting board. Trace a journey from A1 to D3 using right and up moves. Change the rule to pass through a checkpoint, close a junction, close just one street, or separate the up moves. **Routes found** keeps distinct completed routes for each rule while you explore. **Explain the count** shows how many completions each next move allows. The activity appears in S052, S093, S227, S248, S318 and S366. [Try the S318 investigation](https://simonrj.github.io/-summit-one-narrator/watch-lesson-intro.html?slot=318#lessonModel).

Ten worked examples also let students compare two approaches. In sessions 2, 13, 26, 43, 62, 86, 142, 179, 298 and 332, open **Show all steps**, then **Another way**. For example, S002 compares working from 30 × 8 with doubling 31 three times. Both activities are optional and ungraded. The comparison draws on [Pam Harris and Kim Montague’s #MathStratChat](https://podcast.mathisfigureoutable.com/1062400/episodes/20096281-mathstratchat-november-18-2026).

**Student access.** Open the current session and choose **Watch video** after the reading. After the video, choose **Start practice**. The learner can work on paper, ask for a hint where one is provided, enter a final answer, and then open the worked solution. **Menu → Completed sessions → Read the lesson and revisit practice** opens the revised material for a completed session without replacing the locked record.

## Rebuilding or extending

The learner-facing text is [data/read-watch-practise.json](../data/read-watch-practise.json). Graded answers and worked solutions are private. To reconstruct the edition, unpack its private authoring archive outside the repository, run its three verification programs, then run `python tools/content/build_read_practice.py /path/to/private-edition` in a checkout. The generator writes the public release inside the repo and the grading rows, expected digest and a verification query in the private source directory. Run `node tools/check_read_practice.mjs` to check the edition, the order of every question, the film mapping and the absence of scored answers in the public file.

The November review revised the private explanations for O003X, RWL1-002-A, RWL1-006-D, RWL1-010-A and RWL1-013-D. If an older authoring archive contains the original wording, use an authorised database session to run the query below. Save its returned JSON object as `practice-revision-solutions.json` beside the private originals authoring file and in the private first-edition authoring directory. Both builds verify the revised wording against published SHA-256 digests. The O001X supplement is stored separately in the protected `solution_clarifications` table.

```sql
select jsonb_object_agg(id, solution_text) as private_solution_overlay
from public.content_problems
where id in ('O003X', 'RWL1-002-A', 'RWL1-006-D', 'RWL1-010-A', 'RWL1-013-D');
```

New questions use versioned identifiers. Never change an attempted problem when revising a future edition. Old problems omitted from the new route remain intact in the original bank and in historical records. The existing protected grading and solution functions continue to handle submissions.
